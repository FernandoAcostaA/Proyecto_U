# Tutoría

Aquí el tutor deja las observaciones de cada revisión, en archivos con fecha
(`AAAA-MM-DD-<tema>.md`).

Cómo responder: debajo de cada observación, en el mismo archivo, escribir

- **Corregido:** en qué archivo o sección quedó, o
- **No corregido:** por qué.

El avance se sube 48 horas antes de la sesión semanal.
