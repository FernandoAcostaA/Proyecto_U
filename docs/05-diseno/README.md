# Diseño

Diagramas en imagen y con su archivo fuente editable. Deben coincidir con el código.

## Qué debe haber aquí

- [ ] Casos de uso y diagramas de actividades
- [ ] Diagrama de clases (con métodos y tipos de relación), secuencia, componentes y despliegue
- [ ] Modelo entidad-relación, script SQL o migraciones, diccionario de datos
- [ ] Normalización hasta tercera forma normal, explicada con tablas propias
- [ ] Prototipos de pantalla
- [ ] Matriz de trazabilidad requisito – diseño – prueba
