# Perfil y cartas

Documentos que respaldan que el proyecto está aprobado y que la empresa lo autoriza.

## Qué debe haber aquí

- [ ] Perfil aprobado (PDF) y observaciones del docente de Modalidad de Grado II
- [ ] Carta de aceptación de la empresa u organización
- [ ] Acuerdo de confidencialidad, si el documento usa un nombre ficticio
- [ ] Datos de contacto de la persona de la empresa que valida los requisitos
