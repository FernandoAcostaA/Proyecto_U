# Diagnóstico

Evidencia del levantamiento de información en la empresa. Sin estos archivos el diagnóstico del documento no tiene respaldo.

## Qué debe haber aquí

- [ ] Guías de entrevista y entrevistas realizadas (fecha, cargo del entrevistado, respuestas)
- [ ] Fichas de observación llenadas
- [ ] Encuestas: cuestionario, respuestas y tabulación
- [ ] Copias o fotos de los registros actuales (cuadernos, planillas, hojas de cálculo)
- [ ] Diagrama del proceso actual
- [ ] Medición de la línea base: indicador, valor, fecha, cómo se midió
