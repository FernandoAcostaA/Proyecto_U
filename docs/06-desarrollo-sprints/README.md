# Desarrollo por sprints

Una subcarpeta por sprint: `sprint-1/`, `sprint-2/`, etc.

## Qué debe haber aquí

- [ ] Planificación del sprint: historias comprometidas y fechas
- [ ] Capturas de pantalla del incremento funcionando
- [ ] Revisión con el usuario: qué aceptó y qué pidió cambiar
- [ ] Retrospectiva
- [ ] Tablero o gráfico de avance
